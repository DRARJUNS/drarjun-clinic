Cloud Email Setup (Render / Free API)

Render blocks standard SMTP ports. Use Brevo (100% free, 300 emails/day) or Gmail SMTP:

  1. Option A: Brevo (Recommended for Render):
    • Sign up free at brevo.com.
    • Go to SMTP & API > Generate an API Key.
    • In Render Dashboard > Environment, add: BREVO_API_KEY=your_key
  2. Option B: Gmail App Password (Localhost): 
    SMTP_USER=drarjunshomoeocare@gmail.com
SMTP_PASS=your_16_character_app_password
